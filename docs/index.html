DS4Arduino

Native DualShock 4 Bluetooth Classic HID host for the original ESP32.
No console, no dongle, no extra dependencies.

input validated on hardware

Open live controller test Install

Install

  1. Arduino IDE → Sketch → Include Library → Add .ZIP (this repo), or clone into Documents/Arduino/libraries/DS4Arduino.
  2. Board: DOIT ESP32 DEVKIT V1 (or any original ESP32 with Bluetooth Classic).
  3. Flash File → Examples → DS4Arduino → BasicConnect.
  4. Open Serial Monitor at 115200, hold SHARE + PS until the light bar flashes white.

Requires Arduino-ESP32 2.x/3.x on an original ESP32 (S3/C3/C6 have no Classic radio and report Not supported instead of failing silently).

Minimal sketch

 #include <DS4Arduino.h>

DS4Controller ds4;

void setup() {
    Serial.begin(115200);
    ds4.begin();
}

void loop() {
    ds4.update();
    if (!ds4.connected()) return;
    Serial.printf("LX=%d LY=%d RX=%d RY=%d\n",
        ds4.leftStickX(), ds4.leftStickY(),
        ds4.rightStickX(), ds4.rightStickY());
}

Pairing

  1. Flash a sketch, power the ESP32, open Serial Monitor (115200).
  2. Controller light bar off (hold PS ~10 s, unplug USB).
  3. Hold SHARE + PS until the light bar flashes white rapidly.
  4. Wait for DS4 found → Connecting... → DS4 connected.
  5. The bond is stored (NVS on ESP32), so reconnects need no re-pairing — just tap PS to wake.

A controller previously bonded elsewhere may need its reset hole (paperclip, 5 s) before it accepts a new host.

API reference

CallMeaning
begin() / end()Start/stop Bluetooth + discovery
update()Drain + parse queued reports (call each loop())
connected()True once both HID channels are up
statusText() / lastErrorText()Human-readable state / sticky error
leftStickX/Y(), rightStickX/Y()0..255, centre 128
l2(), r2()Analog triggers 0..255
cross/circle/square/triangle()Face buttons
l1/r1/l3/r3()Shoulders + stick clicks
share/options/ps/touchpad()System buttons
dpad() + dpadUp/Down/Left/Right()Hat 0..7, 8 = released
gyroX/Y/Z(), accelX/Y/Z()Raw int16 motion
touch0/1Active/X/Y()Touchpad contacts (0..1920 / 0..942)
batteryLevel() / charging()0..10 + charging flag
setLED(r,g,b) / setRumble(small,large)Light bar + rumble over Bluetooth
packetCount()Parsed-report counter (spot drops)

Examples

  • BasicConnect — connection + sticks/triggers/buttons/battery.
  • ControllerTest — press-every-button check with edge prints, LED stepping, plus 20 Hz $DS4 machine lines for the live test page.
  • RCCar — TB6612FNG car: left-stick Y = throttle, right-stick X = steering (motor code lives only in the example).

Machine protocol ($DS4)

$DS4,SEQ,LX,LY,RX,RY,L2,R2,B0,B1,B2,BATT,CHG,GX,GY,GZ,AX,AY,AZ,T0A,T0X,T0Y,T1A,T1X,T1Y*CS

B0 = hat + face bits, B1 = shoulders/system, B2 = PS/touchpad/counter. CS = XOR of bytes between $ and * as 2 hex digits. Lines starting with # are human comments.

Troubleshooting

  • Not supported on this hardware/core — S3/C3/C6 board or BT disabled; use an original ESP32.
  • Never finds the DS4 — controller not in flashing-white SHARE+PS mode; move closer; unplug USB.
  • Connects then drops — unstable 5 V supply is the usual cause.
  • Only small reports / no gyro — full 0x11 mode enables after the first output report, which the library sends on connect.
  • Stuck after switching hosts — reset the controller (paperclip, 5 s), then SHARE+PS.
